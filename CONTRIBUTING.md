# Contributing

Contributions are welcome. Before adding records or adapters:

- Preserve source identifiers and source URLs.
- Do not invent missing dates, lineups, or relationships.
- Record licensing and API restrictions in the adapter documentation.
- Add tests for parsing and normalization.
- Keep subjective rankings out of the core dataset unless their methodology
  is explicit, reproducible, and clearly labeled.

Please open an issue before making large schema changes.
